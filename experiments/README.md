# TTS-эксперименты

Здесь лежат разовые probes, численные сравнения и промежуточные реализации,
которые использовались при переносе VoXtream2-RU на TensorRT и CUDA.

Стабильным интерфейсом считается только код из `src/voxtream2_ru_jetson/`.
Экспериментальные файлы сохранены, чтобы выводы можно было проверить, но они
могут требовать отдельного окружения или более раннего набора assets.
